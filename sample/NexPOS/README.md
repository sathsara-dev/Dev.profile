# 🏪 NexPOS - Modern Cloud-Based Point of Sale System

NexPOS is a full-stack, enterprise-grade Point of Sale (POS) solution designed for modern retail businesses. It features a responsive React frontend with a high-performance Python Flask backend to manage inventory, sales, and real-time billing.

![NexPOS Screenshot](Add-Your-Screenshot-Here.png)

## 🚀 Key Features
- **Full-Stack Architecture:** Seamless communication between React (Frontend) and Python Flask (Backend).
- **Interactive POS Interface:** Glassmorphism UI with category filtering (Food, Drinks, Snacks).
- **Real-Time Cart System:** Dynamic calculation of subtotals, taxes, and grand totals.
- **Backend API:** Python-based REST API for product management and order processing.
- **Search & Filter:** Instant product search and category switching.

## 🛠️ Tech Stack
- **Frontend:** React JS, Lucide React, CSS3 (Glassmorphism)
- **Backend:** Python Flask, Flask-CORS
- **State Management:** React Hooks (useState, useEffect)
