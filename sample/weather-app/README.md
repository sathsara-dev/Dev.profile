# 🌤️ WeatherPro - Modern Glassmorphism Weather App

A stunning, futuristic weather dashboard built with **React JS**. Featuring a dynamic "Dark Aurora" glassmorphism UI, this application provides real-time weather updates and a 7-day forecast using the Open-Meteo API.



## 🚀 Features
- **Glassmorphism UI:** Modern translucent cards with backdrop blur effects.
- **Dynamic Backgrounds:** Animated aurora blobs for a premium visual experience.
- **Real-time Data:** Fetches live weather data based on city search.
- **7-Day Forecast:** Scrollable forecast strip with daily predictions.
- **Responsive Design:** Optimized for all screen sizes.

## 🛠️ Tech Stack
- **Frontend:** React JS, CSS3 (Animations & Gradients)
- **API:** Open-Meteo (No API Key required)
- **Icons:** Phosphor Icons / Lucide React
