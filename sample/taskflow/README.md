# 📋 TaskFlow Pro - Advanced Kanban Project Management Tool

TaskFlow Pro is a next-generation productivity tool inspired by Jira and Trello. It features a robust **Drag-and-Drop** system, a futuristic Cyberpunk aesthetic, and local storage persistence for managing tasks efficiently.

![TaskFlow Screenshot](Add-Your-Screenshot-Here.png)

## 🚀 Key Features
- **Drag & Drop Engine:** Powered by `@hello-pangea/dnd` for smooth task movement between columns.
- **Theme Switcher:** Toggle between **Cyberpunk Dark** and **Clean Light** modes instantly.
- **Priority System:** Visual tags for High, Medium, and Low priority tasks.
- **Persistent Storage:** Tasks are saved in the browser's Local Storage (No data loss on refresh).
- **Search & Filter:** Real-time filtering of tasks across columns.

## 🛠️ Tech Stack
- **Framework:** React JS
- **Library:** @hello-pangea/dnd (Drag and Drop)
- **Styling:** CSS Variables (Theming), Glassmorphism
- **Icons:** Lucide React
