\# 🍿 MovieFlix - Cinematic Mobile Experience



A premium, Netflix-inspired movie discovery application built with \*\*React Native (Expo)\*\*. Designed with a dark cinematic aesthetic, this app provides a seamless browsing experience with immersive grid layouts, gradient overlays, and real-time movie data.



!\[MovieFlix Showcase](Add-Your-Screenshot-Here.png)



\## 🚀 Key Features

\- \*\*Cinematic UI:\*\* Deep dark theme with `#0f1014` background for a theater-like feel.

\- \*\*Gradient Overlays:\*\* Professional text visibility using linear gradients over movie posters.

\- \*\*Smart Grid System:\*\* Responsive 2-column layout that adapts to screen width.

\- \*\*Real-time Data:\*\* Fetches live movie shows using the TVMaze API.

\- \*\*Search Functionality:\*\* Instant search to find your favorite titles.

\- \*\*Profile Section:\*\* Personalized header with user avatar.



\## 🛠️ Tech Stack

\- \*\*Framework:\*\* React Native (Expo)

\- \*\*Styling:\*\* StyleSheet, Expo Linear Gradient

\- \*\*Icons:\*\* Ionicons (@expo/vector-icons)

\- \*\*API:\*\* TVMaze (Open API)

\- \*\*Components:\*\* FlatList, TouchableOpacity, ActivityIndicator
