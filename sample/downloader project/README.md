\# ⚡ NeonFlow - Modern YouTube Downloader



A premium desktop application for downloading YouTube videos and audio. Built with \*\*Python \& CustomTkinter\*\*, it features a cyberpunk-inspired dark UI with threading support to ensure a smooth user experience without freezing.



!\[Project Screenshot](Add-Your-Screenshot-Here.png)



\## 🚀 Features

\- \*\*Modern GUI:\*\* Sleek dark mode interface using CustomTkinter.

\- \*\*Format Selection:\*\* Choose between Video (MP4) or Audio (MP3).

\- \*\*Hacker Console:\*\* Real-time log display resembling a terminal.

\- \*\*Multi-Threading:\*\* Downloads run in the background without freezing the UI.

\- \*\*Progress Tracking:\*\* Live progress bar for downloads.



\## 🛠️ Tech Stack

\- \*\*Language:\*\* Python 3.x

\- \*\*GUI Library:\*\* CustomTkinter

\- \*\*Core Engine:\*\* yt-dlp

\- \*\*Processing:\*\* Threading, FFmpeg
