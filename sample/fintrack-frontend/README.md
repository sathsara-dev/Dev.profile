\# 📊 FinTrack - Enterprise Finance Dashboard



A comprehensive Full Stack Expense Tracker Dashboard built with \*\*React (Frontend)\*\* and \*\*Python Flask (Backend)\*\*. It features an Apple Vision Pro-inspired UI with advanced data visualization using Chart.js.







\## 🚀 Features

\- \*\*Full Stack Architecture:\*\* REST API communication between Python \& React.

\- \*\*Data Visualization:\*\* Interactive Line charts and Doughnut charts.

\- \*\*Vision Pro UI:\*\* Glassmorphism, neon glows, and floating elements.

\- \*\*Transaction History:\*\* Detailed list of recent income and expenses.

\- \*\*KPI Cards:\*\* Instant view of Total Balance, Income, and Savings.



\## 🛠️ Tech Stack

\- \*\*Frontend:\*\* React JS, Chart.js, Axios, Lucide React

\- \*\*Backend:\*\* Python Flask, Flask-CORS

\- \*\*Styling:\*\* CSS3 (Advanced Backdrop Filters)
