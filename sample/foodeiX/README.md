# 🍔 FoodieX - Premium Food Delivery App

A high-end mobile application built with **React Native & Expo**. Designed with a "Vision Pro" dark aesthetic, featuring complex animations, a fully functional cart system, and dynamic interactions.



## 🚀 Master Features
- **Immersive UI:** Dark theme with orange neon glows and glass effects.
- **Smart Filtering:** Dynamic category switching and search functionality.
- **Interactive Cart:** Add/Remove items, quantity adjustment, and real-time total calculation.
- **Bottom Sheet Modal:** Advanced popup for product details and customization.
- **Favorites System:** Wishlist functionality with persistent state.

## 🛠️ Tech Stack
- **Framework:** React Native (Expo)
- **Styling:** Expo Blur, Linear Gradient
- **Icons:** Ionicons, MaterialCommunityIcons
- **Animations:** LayoutAnimation API
