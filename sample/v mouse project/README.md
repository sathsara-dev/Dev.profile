\# 🖐️ AI Virtual Mouse - Gesture Control System



Control your computer mouse using hand gestures! This project utilizes \*\*Computer Vision (OpenCV)\*\* and \*\*MediaPipe\*\* to track hand landmarks in real-time, allowing for touch-free interaction.





\## 🚀 Features

\- \*\*Hand Tracking:\*\* Real-time finger detection using MediaPipe.

\- \*\*Cursor Control:\*\* Move the mouse pointer with your index finger.

\- \*\*Click Action:\*\* Pinch (Index + Thumb) to perform a mouse click.

\- \*\*Smoothening:\*\* Algorithm to reduce cursor jitter for precision.

\- \*\*Frame Rate Display:\*\* Live FPS monitoring.



\## 🛠️ Tech Stack

\- \*\*Python\*\*

\- \*\*OpenCV\*\* (Image Processing)

\- \*\*MediaPipe\*\* (Hand Tracking Model)

\- \*\*PyAutoGUI\*\* (Mouse Control)

\- \*\*NumPy\*\* (Math Calculations)
