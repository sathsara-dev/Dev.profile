# 🏠 NexusHome Pro - Ultimate IoT Smart Home Dashboard

A premium mobile application for controlling smart home devices. Built with **React Native & Expo**, this app features a high-end UI with interactive hardware controls, energy monitoring, and smart automation scenes.

![NexusHome Screenshot](Add-Your-Screenshot-Here.png)

## 🚀 Key Features
- **Interactive Controls:** Long-press for **RGB Color Picker**, Sliders for Brightness/Temperature.
- **Smart Automation:** One-tap "Scenes" (Movie Mode, Away Mode) that automate multiple devices.
- **Energy Monitoring:** Visual weekly power usage graphs.
- **Device Scanning:** Simulated Bluetooth/WiFi scanning animation for new devices.
- **Secure Access:** Biometric-style Smart Lock interface with vibration feedback.

## 🛠️ Tech Stack
- **Framework:** React Native (Expo)
- **UI Components:** Expo Blur, Linear Gradient, React Native Community Slider
- **Animations:** React Native LayoutAnimation & Modal Transitions
- **Icons:** Expo Vector Icons
